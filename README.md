# GSE114517-Parkinson-s-disease-data-analysis
# Target Gene Expression Analysis

## Project Goal
To check the expression of specific target genes KEAP1, NFE2L2, CUL3, GSK3B, SOD1, NQO1, GCLC, HMOX1, SNCA, TH, ESR1 under Parkinson's disease + dementia compared to non-demented Parkinson's disease control.

## Methodology
- Cleaned the raw expression data.
- Isolated the expression values for only the predefined target genes.
- Calculated the changes to see if they match my wet-lab expectations.

## Key Files
- `GSE114517_SN_Normalized_with_genenames.csv`: Contains the expression values and statistical outputs for the target genes.

Used the file generated from GSE114517 R studio to perform further analysis.
